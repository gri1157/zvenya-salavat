# Звенья Салавата

Приложение со статистикой хоккейного клуба «Салават Юлаев» в сезоне FONBET КХЛ 2026/27.

## Что внутри

- **Состав**: модель четырёх пятёрок, вратари, запас и народный состав, который собирают болельщики.
- **Матчи и таблица**: шансы на ближайший матч, календарь, турнирная таблица КХЛ.
- **Игроки**: статистика сезона, сравнение двух игроков, карточка каждого игрока.
- **Лидеры КХЛ**: лучшие нападающие, защитники и вратари лиги.
- **Pro-режим**: план на матч, разбор соперника, время на льду и броски, форма, спецбригады, разделы для генменеджера и агента.

Есть русский и английский язык, светлая и тёмная тема, версии Lite и Pro.

## Откуда данные

Официальный сайт КХЛ (протоколы матчей и статистика игроков), Sports.ru, Спорт-Экспресс и Allhockey. Данные обновляются каждое утро после матчей.

## Как открыть

Приложение опубликовано здесь: https://claude.ai/artifact/V8o3puVaXvF8S2JSjGP7oX

Можно открыть и файл `index.html` в браузере, но голосование и игра для болельщиков работают только в опубликованной версии.

## Команда, которая следит за приложением

| Кто | Когда | Что делает | Что получается |
|---|---|---|---|
| Сборщик данных | каждое утро, 10:45 по Уфе | вносит вчерашние матчи и статистику, публикует приложение и кладёт его сюда | свежий `index.html` |
| Сверщик данных | каждое утро после сборщика | сверяет ключевые цифры с открытыми источниками | задача с меткой `data-check` |
| Автопроверка | после каждого изменения | без ИИ: ошибки страницы, внутренние сверки, вёрстка на телефоне | зелёная или красная галочка |
| Тестировщик Lite | пн и чт, 12:00 по Уфе | ищет поломки, которые мешают болельщику | задача `qa-report` |
| Тестировщик Pro | пн и чт | ищет поломки у тренера, генменеджера и агента | задача `qa-report` |
| Критик | после тестировщиков | сам повторяет каждую ошибку, мусор отсеивает | задачи `bug` с важностью |
| Исправитель | после критика | чинит 1–3 подтверждённые ошибки | pull request `fix` |
| Проверяющий | после исправителя | проверяет, что исправление работает и ничего не сломало | вердикт в pull request |
| Фиксатор прогнозов | за 10 минут до каждого матча | копирует прогнозы «Моей игры» в закрытое хранилище, чтобы их нельзя было поменять после начала | документ в `gameseal`, по нему считаются очки |
| Консилиум | чт, 16:00 по Уфе | одна страница за неделю: что исправлено, что ждёт решения, идеи | задача `council` |

Владелец раз в неделю читает консилиум и принимает исправления с вердиктом «принять» кнопкой **Merge pull request**. На следующее утро сборщик публикует их в приложении.

Роли описаны в папке `.github/agents/`, порядок работы — в `.github/workflows/`.
