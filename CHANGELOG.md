# История версий

Версия приложения `APP_VERSION` в index.html (показывается над переключателем Lite/Pro вверху приложения как v1.N). Каждое слияние в main = новая версия: 1.52, 1.53, 1.54 и дальше по порядку. Проверка в PR не даст слить без повышения версии.
Номер данных `UPDATED.n` («№…») — отдельный счётчик обновлений статистики сборщиком.

- **v1.54** — травмы: Ремпал внесён в список травмированных (18.11, КХЛ), Горшков убран из травмированных (сыграл 18.11 с Барысом).

- **v1.52** — версия в приложении и правило «каждое слияние — новая версия». До этого: кнопки сезонов 26/27, 25/26, 24/25, «Все сезоны», «Последние матчи» с ползунком (PR #51); результаты и игроки сверяются скриптами (PR #47–#50); таблица КХЛ по расписанию без ИИ (PR #44–#45); защита выкладки на сервер (PR #46); привратник сборщика (PR #48); этапы 2–3 (PR #40–#43); матч 18.11 с протоколом КХЛ (PR #41).
